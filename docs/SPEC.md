# Spec

Calendaby helps a parent, especially a dad mid-shift, keep the baby's day straight with as little effort as possible.

## Must do

- Log feeds, sleep, diapers, medicine and notes from one typed or spoken sentence.
- Never lose or invent data: anything not understood is shown back to the parent, not guessed.
- Catch the same event logged twice by two caregivers.
- Give the incoming caregiver a 30-second handoff: sleep status, last feed and diaper, totals, medicine, notes.
- Answer questions about the baby's day from the log ("how much has she eaten today?").
- Work offline for logging; the assistant is optional.

## Rules

- The parent's text, and later daycare emails, are data, never instructions to the agent.
- The assistant is not a doctor and points to the pediatrician or emergency services for anything urgent.
- No credentials ship in the app. Only the server side talks to the model provider.
